# CNC Sketch Manager - User Guide

## Overview

The CNC Sketch Manager is a complete solution for saving drawings created in the LVGL CNC UI and automatically converting them to G-code for CNC machine execution. This system bridges the gap between digital design and physical manufacturing.

## Architecture

### Three-Layer System

```
┌──────────────────────────────────────────────────────────┐
│  1. UI LAYER - CNC Drawing Interface (cnc_ui.c)         │
│     • Draw lines, circles, rectangles, dimensions       │
│     • Real-time preview on touchscreen                  │
│     • Live coordinate and zoom display                  │
└──────────────────────────────────────────────────────────┘
                         ↓
┌──────────────────────────────────────────────────────────┐
│  2. SKETCH MANAGEMENT LAYER (cnc_sketch.c)             │
│     • Save sketches as JSON files                       │
│     • Load sketches from storage                        │
│     • Manage sketch metadata and history                │
└──────────────────────────────────────────────────────────┘
                         ↓
┌──────────────────────────────────────────────────────────┐
│  3. G-CODE GENERATION LAYER (cnc_sketch.c)             │
│     • Convert drawing elements to G-code commands       │
│     • Calculate tool paths and feed rates               │
│     • Generate CNC machine-ready files                  │
└──────────────────────────────────────────────────────────┘
```

## Features

### 1. **Save Sketch** (💾 Button)
Saves the current drawing to a JSON file with:
- **Filename**: `sketch_YYYYMMDD_HHMMSS.json`
- **Location**: `/tmp/cnc_sketches/`
- **Content**:
  - Job name, size, and rotation
  - All drawn lines with coordinates and colors
  - All circles with center, radius, and colors
  - All rectangles with boundaries and colors
  - All dimensions with measurements

**Example Output:**
```json
{
  "version": "1.0",
  "timestamp": 1715337600,
  "description": "User sketch from CNC UI",
  "job": {
    "name": "New Job",
    "width_mm": 100.00,
    "height_mm": 100.00,
    "rotation": 0.00
  },
  "lines": [
    {
      "x1": 50,
      "y1": 50,
      "x2": 150,
      "y2": 150,
      "width": 2,
      "color": "#38BDF8"
    }
  ],
  "circles": [...],
  "rectangles": [...],
  "dimensions": [...]
}
```

### 2. **Export G-Code** (⚙ Button)
Generates CNC machine-ready G-code with:
- **Filename**: `job_YYYYMMDD_HHMMSS.gcode`
- **Location**: `/tmp/cnc_gcode/`
- **Default Parameters**:
  - Tool diameter: 1.5 mm
  - Feed rate: 100 mm/min
  - Spindle speed: 3000 RPM
  - Safe Z height: 5.0 mm

**G-Code Structure:**
```gcode
(Generated by CNC Sketch Manager)
(Job: New Job)
(Date: May 29 2026)
(Tool Diameter: 1.5 mm, Feed Rate: 100.00, Spindle: 3000 RPM)

G21          (Metric units)
G90          (Absolute positioning)
G17          (XY plane)
M3 S3000     (Start spindle at 3000 RPM)
G4 P1        (Wait 1 second for spindle to spin up)

G0 Z5.00     (Move to safe height)

(========== LINES ==========)
(Line 1)
G0 X5.00 Y5.00            (Rapid move to start)
G1 Z-1.0 F100.00          (Move to cutting depth)
G1 X15.00 Y15.00 F100.00  (Cut line)
G0 Z5.00                  (Retract)

(========== CIRCLES ==========)
(Circle 1 - Center: (10.00, 10.00), Radius: 5.00 mm)
...

(========== RECTANGLES ==========)
(Rectangle 1)
...

G0 Z5.00           (Move to safe height)
G0 X0 Y0          (Move to origin)
M5                (Stop spindle)
M30               (End program)
```

## How to Use

### Drawing on Screen

1. **Start the Application**:
   ```bash
   cd /home/user/Desktop/Lvgl_Project/lv_port_linux/build
   sudo ./bin/lvglsim
   ```

2. **Select Drawing Tool**:
   - **Line Tool**: Draw straight lines
   - **Circle Tool**: Draw circles (drag from center)
   - **Rectangle Tool**: Draw rectangles (drag diagonal)
   - **Dimension Tool**: Add dimension measurements
   - **Pan Tool**: Move the view
   - **Zoom Tool**: Zoom in/out

3. **Configure Drawing Parameters**:
   - Use **stroke width slider** to adjust line thickness
   - Click **color buttons** to select draw color
   - Toggle **grid** for alignment help

4. **Undo/Clear/Fit-to-View**:
   - **✕**: Clear all drawings
   - **↶**: Undo last drawing
   - **+/-**: Zoom in/out
   - **⬚**: Fit drawing to view

### Saving and Exporting

5. **Save Current Sketch**:
   - Click the **💾 (Save)** button
   - Sketch is automatically saved with timestamp
   - Message "✓ Sketch Saved!" appears

6. **Export to G-Code**:
   - Click the **⚙ (Export)** button
   - G-code file is generated with CNC machine parameters
   - Message "✓ G-Code Generated!" appears

### Accessing Files

**View Saved Sketches:**
```bash
ls -la /tmp/cnc_sketches/
```

**View Generated G-Code:**
```bash
ls -la /tmp/cnc_gcode/
cat /tmp/cnc_gcode/job_*.gcode
```

## Coordinate System

### Pixel to Millimeter Conversion
- **Formula**: `mm = pixels × 0.1`
- **Calibration**: Default is 0.1 mm per pixel
- **Adjustment**: Modify `pixels_to_mm()` function in `cnc_sketch.c`

### Coordinate Origin
- **(0, 0)**: Top-left of canvas
- **X-axis**: Left → Right (horizontal)
- **Y-axis**: Top → Bottom (vertical)
- **Z-axis**: Up → Down (depth, for CNC cutting)

## CNC Machine Integration

### Using G-Code Files

1. **Transfer File to CNC Machine**:
   ```bash
   # Copy to USB or network share
   cp /tmp/cnc_gcode/job_*.gcode /mnt/usb/
   ```

2. **Load in CNC Software**:
   - Use your CNC machine's software (LinuxCNC, Mach3, etc.)
   - Import the .gcode file
   - Verify tool paths and dimensions

3. **Run on Machine**:
   - Install the correct tool (1.5mm default)
   - Set spindle speed to 3000 RPM
   - Clamp workpiece securely
   - Start the program

### Customizing G-Code Parameters

Edit the export function to change default parameters:

```c
// In cnc_ui.c, btn_export_gcode_event function:
if (cnc_gcode_generate(fullpath, 
                       1.5f,    // Tool diameter in mm
                       100.0f,  // Feed rate in mm/min
                       3000))   // Spindle speed in RPM
```

## API Reference

### Header File: `cnc_sketch.h`

#### Save Function
```c
bool cnc_sketch_save(const char *filename, const char *description);
```
- **Parameters**:
  - `filename`: Output filename (e.g., "my_sketch.json")
  - `description`: Optional description of sketch
- **Returns**: `true` on success, `false` on error
- **Storage**: `/tmp/cnc_sketches/`

#### Load Function
```c
bool cnc_sketch_load(const char *filename);
```
- **Parameters**:
  - `filename`: Sketch filename to load
- **Returns**: `true` on success, `false` on error
- **Effect**: Clears current drawing and loads sketch

#### G-Code Generation
```c
bool cnc_gcode_generate(const char *output_file, 
                        float tool_diameter_mm, 
                        float feed_rate, 
                        uint32_t spindle_speed);
```
- **Parameters**:
  - `output_file`: Full path to output G-code file
  - `tool_diameter_mm`: Tool size (for offset calculations)
  - `feed_rate`: Tool movement speed (mm/min)
  - `spindle_speed`: Rotation speed (RPM)
- **Returns**: `true` on success
- **Example**:
  ```c
  cnc_gcode_generate("/tmp/cnc_gcode/part.gcode", 
                     1.5f,    // 1.5mm tool
                     80.0f,   // 80 mm/min speed
                     2500);   // 2500 RPM spindle
  ```

## Technical Details

### JSON Format Specification

**File Structure**:
```
{
  "version": "1.0",
  "timestamp": <unix_time>,
  "description": "<optional_text>",
  "job": {
    "name": "<job_name>",
    "width_mm": <float>,
    "height_mm": <float>,
    "rotation": <float>
  },
  "lines": [
    { "x1": int, "y1": int, "x2": int, "y2": int, 
      "width": int, "color": "#RRGGBB" }
  ],
  "circles": [
    { "cx": int, "cy": int, "radius": int, 
      "width": int, "color": "#RRGGBB" }
  ],
  "rectangles": [
    { "x1": int, "y1": int, "x2": int, "y2": int, 
      "width": int, "color": "#RRGGBB" }
  ],
  "dimensions": [
    { "x1": int, "y1": int, "x2": int, "y2": int, 
      "length_mm": float, "label": "<text>" }
  ]
}
```

### G-Code Commands Used

| Command | Description | Example |
|---------|-------------|---------|
| G0 | Rapid positioning | `G0 X10 Y20` |
| G1 | Linear interpolation (cutting) | `G1 X15 Y25 F100` |
| G2 | Circular interpolation (CW) | `G2 X12 Y12 I1 J1 F100` |
| G4 | Dwell (pause) | `G4 P1` (1 second) |
| G17 | XY plane selection | `G17` |
| G21 | Metric units | `G21` |
| G90 | Absolute positioning | `G90` |
| M3 | Spindle on (CW) | `M3 S3000` (3000 RPM) |
| M5 | Spindle off | `M5` |
| M30 | End program | `M30` |

## Troubleshooting

### Issue: "Sketch saved" message doesn't appear

**Solution**: Check directory permissions:
```bash
sudo mkdir -p /tmp/cnc_sketches /tmp/cnc_gcode
sudo chmod 777 /tmp/cnc_sketches /tmp/cnc_gcode
```

### Issue: G-code not generating

**Solution**: Ensure sufficient disk space:
```bash
df -h /tmp/
```

### Issue: G-code produces incorrect tool paths

**Solution**: Verify and adjust parameters in `btn_export_gcode_event()`:
- Check tool diameter matches your CNC tool
- Adjust feed rate for your machine
- Verify spindle speed is within machine limits

### Issue: Sketches don't load properly

**Solution**: Sketch loading requires a JSON parser. Current implementation is simplified.
For production, consider integrating a JSON library like **cJSON** or **jsmn**.
